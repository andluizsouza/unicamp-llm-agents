# Bloco A: Introdução aos Agentes Inteligentes

## TL;DR / Resumo Executivo
Esta seção introduz o paradigma de agentes inteligentes com LLMs, mostrando como um modelo de linguagem pode ser transformado em um sistema capaz de perceber, raciocinar, planejar, agir e interagir com um ambiente para alcançar objetivos específicos. O foco é construir uma base conceitual sólida sobre o que é um agente, quais componentes o compõem, como especificá-lo corretamente e como aplicá-lo em cenários reais de software e automação.

## Conceitos Fundamentais (Tópicos Abordados)

- **Agentes Inteligentes**: definição de agente como software que percebe o ambiente e atua sobre ele, com autonomia, reatividade, proatividade e sociabilidade.
- **LLM como "cérebro" do agente**: o modelo de linguagem fornece raciocínio e compreensão de linguagem, mas precisa ser integrado a outros componentes para agir de forma efetiva.
- **Componentes de um agente**: planejamento, ferramentas, ações e memória como pilares da arquitetura de um agente completo.
- **Memória e estado**: diferenciação entre memória de curto e longo prazo, além do papel do estado interno na continuidade de tarefas.
- **Especificação de agentes**: definição de objetivo, ambiente, entradas, estado, habilidades, ferramentas, saídas, métricas e autonomia.
- **Prática e implementação**: uso de um notebook para explorar conceitos introdutórios e construir uma primeira visão aplicada do tema.
